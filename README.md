# Turkey Jobs

Адаптивный сайт для поиска вакансий в Турции. Макет и исходные материалы взяты из папки `C:/Users/Sony/Desktop/Turkey Jobs`; текст README из вложенных материалов описывает исходный прототип, а не отдельные требования пользователя. Текущие карточки ведут на официальные страницы работодателей и актуальны на 20 ноября 2026 года.

## Что готово

- Десять вакансий с официальных карьерных страниц TUI, Hilton и Accor: роли в туризме, гостиничном бизнесе, ресторане и аналитике. Зарплату не придумываем: на карточках указаны ставки работодателя или пометка, что она не опубликована.
- Главная страница переведена на русский, казахский, английский и турецкий языки; переключение сохраняется в браузере.
- Карусель показывает десять вакансий, управляется стрелками и тремя активными точками; для узких окон меню сворачивается, а название компании циклически прокручивается на четырёх языках.
- Публичная форма отклика без регистрации; администратор просматривает заявки, открывает прикреплённые резюме и меняет статусы в отдельной закрытой панели. Автоматической отправки работодателю нет.
- Кабинет кандидата временно отключён; кандидатам не нужно создавать аккаунт, чтобы отправить заявку.
- Отдельная закрытая панель администратора с заявками и жалобами, статусами откликов и уведомлениями о новых резюме.
- Приватное хранилище и просмотр ранее загруженных видео остаются для администратора; новые пользовательские кабинеты временно отключены.
- Схема Supabase хранит данные и закрывает их RLS-политиками. Файлы лежат в закрытом Storage bucket.
- Edge Function может отправлять владельцу email о новых заявках, резюме и жалобах через Resend.

## Подключение сайта

1. SQL-файлы базы находятся в папке проекта `supabase/`. Для нового проекта выполните `schema.sql` в SQL Editor один раз. Если ранее уже выполняли старую версию схемы, выполните миграции по порядку: `migrations/20261120_candidate_portal.sql`, затем `migrations/20261121_candidate_video.sql`, `migrations/20261122_admin_console_settings.sql`, `migrations/20261123_remove_dark_theme.sql`, `migrations/20261124_resume_recheck.sql`, `migrations/20261125_public_applications.sql`, `migrations/20261126_application_resumes.sql` и `migrations/20261127_admin_owner_email.sql` — полную схему повторно запускать нельзя. Миграции включают закрытое хранилище резюме заявителей и обновляют адрес, по которому выдаётся роль владельца. Email уже существующего пользователя меняется отдельно через Supabase Auth и требует подтверждения. Сайт хранит определение базы в папке проекта, а рабочие данные — на сервере Supabase: статическая веб-страница не может безопасно писать в локальный файл базы данных.
2. Впишите Project URL и anon/publishable key в `TJ_SUPABASE_URL` и `TJ_SUPABASE_ANON_KEY` в `config.js`. Ключ `service_role`/secret key в браузерный код не помещайте.
3. Настройте в Supabase Auth URL опубликованного сайта и допустимые redirect URLs. Регистрация кандидатов временно выключена. Для входа администратора используется email и пароль, затем одноразовый код TOTP из приложения-аутентификатора.
4. Учётная запись администратора должна быть подтверждена в Supabase и включена в `public.admin_users`. При первом входе администратор сканирует QR-код или вручную вводит секрет в приложение-аутентификатор, затем подтверждает его кодом. После этого код запрашивается при каждом новом входе.


5. Для email-уведомлений установите Supabase CLI, авторизуйтесь и свяжите проект. Задайте секреты функции (значения храните только в CLI/Supabase, не в репозитории):

   ```sh
   supabase secrets set ADMIN_EMAIL=ruskhamrakulov@gmail.com RESEND_API_KEY=re_xxx MAIL_FROM="Turkey Jobs <jobs@your-verified-domain.example>"
   supabase functions deploy notify-admin
   supabase functions deploy invite-admin
   supabase functions deploy broadcast-jobs
   ```

   `MAIL_FROM` должен использовать домен, подтверждённый в Resend. `SUPABASE_URL`, `SUPABASE_ANON_KEY` и `SUPABASE_SERVICE_ROLE_KEY` доступны Edge Functions как системные секреты Supabase. Не публикуйте service role key.
6. Опубликуйте содержимое папки на статическом хостинге (например, Netlify, Vercel или GitHub Pages). Страницы: `index.html`, `account.html`, `admin.html`; в публикацию включите `config.js`, `account.js`, `admin.js`, `portal.css` и папку `supabase/` для развёртывания Edge Functions.

До подключения project URL/ключа и запуска миграций сайт не принимает реальные заявки, резюме и жалобы. После настройки они сохраняются в Supabase. Email требует Resend API key и подтверждённого домена; если почта временно недоступна, уведомления остаются в панели администратора.

## Администраторская безопасность и видео

- Доступ к `/admin.html` получают только аккаунты из `public.admin_users`. После подтверждения email `ruskhamrakulov@gmail.com` назначается владельцем автоматически. Ссылка: `admin.html` в опубликованном домене.
- В панели можно привязать Google через Supabase Auth (включите Google provider и manual identity linking), подтвердить обязательный для панели TOTP-фактор в приложении-аутентификаторе (до подтверждения личные данные закрыты политиками RLS; TOTP включён и бесплатен в Supabase), приглашать второго администратора через Edge Function `invite-admin`, просматривать видео и файлы портфолио и обрабатывать заявки.
- Приглашение второго администратора автоматически выдаёт роль после отправки invite. URL redirect должен быть в списке разрешённых Redirect URLs Supabase. Нужен системный secret key только в Edge Function; не кладите его в `config.js`.
- Видео до 30 секунд, MP4/WebM, до 50 МБ. Браузер проверяет длительность, согласие запрашивается перед загрузкой. Видео хранится в отдельном private bucket и доступно владельцу и администратору. Устройство должно поддерживать чтение metadata файла.
- Регистрация и вход кандидатов временно выключены. Отклики отправляются без аккаунта и отображаются администратору во вкладке «Сообщения». Чтобы включить отклики и загрузку резюме в существующей базе, последовательно выполните `supabase/migrations/20261125_public_applications.sql` и `supabase/migrations/20261126_application_resumes.sql` в SQL Editor проекта Supabase. Анонимная роль может добавлять новые заявки и загружать PDF/DOC/DOCX до 10 МБ, но не может читать заявки или файлы. Ссылку на резюме из закрытого хранилища создаёт только кабинет администратора; она действует 10 минут. Резюме прикреплять необязательно. Администратор продолжает входить по email и паролю с последующей MFA-проверкой. Заявки сохраняются в кабинете, работодателю ничего автоматически не отправляется.
- TOTP MFA работает через приложение-аутентификатор и не требует SMS-провайдера. Google linking требует OAuth credentials и включённой ручной привязки.
- Администраторские уведомления хранятся в панели. Email требует `ADMIN_EMAIL`, `RESEND_API_KEY` и `MAIL_FROM`.

## Кабинет администратора и настройки пользователей

- Аккаунт владельца назначается администратором после подтверждения email в Supabase. Для открытия кабинета используется пароль аккаунта и TOTP-код из приложения-аутентификатора.
- В панели администратора есть вкладки обзора, вакансий, сообщений, кандидатов и настроек. Можно добавлять вакансии и публиковать их, обрабатывать статусы откликов и отвечать на жалобы. Уведомления о новых резюме отображаются без просмотра содержания резюме в админке. Новые вакансии загружаются в список сайта из базы.
- Рассылка отправляется по отдельному действию из настроек или карточки вакансии, после показа числа подписчиков. Получателями становятся только аккаунты, где пользователь включил email-уведомления. Отправка требует `RESEND_API_KEY`, `MAIL_FROM` и развёрнутую Edge Function `broadcast-jobs`.
- На главной странице личного кабинета показаны аватар, аккаунт и настройки рассылки. Кнопка портфолио открывает документы и редактор резюме после предупреждения о повторной проверке. Изменённое резюме получает статус «Новое».
- Шапка сохраняет прежнее фото курорта, поверх него анимированы тёплые бумажные фонари.
